# Vehicle image credits

The bundled category images in `frontend/public/images/vehicles/` are automotive photographs downloaded
from [Unsplash](https://unsplash.com/license) and served locally with the application. They replace the
previous text-only placeholder URLs so the deployed UI does not depend on an external image placeholder.
